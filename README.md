## 🏛️ Brand & Architectural Overview

**KÉRÀMA ATELIER** is a high-converting, luxury e-commerce portfolio landing page inspired by high-end architectural ceramics, museum gallery curation, and brutal CRO ergonomics.

Designed with an obsession for tactile authenticity, every element adheres to the **Wabi-Sabi & Nordic minimalism** ethos:
- **Canvas Palette:** Warm Japanese Rice paper backdrop (`#FAF7F2`), raw earthenware chalk white, charcoal stone, and vibrant Terracotta Kiln Amber (`#FF723A`).
- **Accent Environments:** Rich, textured dark forest green plaster walls contrasting with raw volcanic stoneware.
- **100% Standalone & Portable:** Single self-contained HTML architecture with all photographic assets embedded as ultra-optimized WebP Base64 strings. Zero external CDN image dependencies.

## ✨ Key Features & UX Innovations

### 1. 🎯 Pixel-Perfect "Shop The Look" Hotspots
- Interactive pulsating terracotta coordinates placed dead-center on individual vessel bodies.
- Fixed 16:9 proportional container scaling ensuring **100% position accuracy across mobile (375px) and ultra-wide PC displays**.
- Dynamic quick-view preview overlays revealing artisanal specifications, dimensions, and instant cart additions.

### 2. 🏺 Interactive Material Finishes & Dynamic Previews
- Multi-finish selector on the Monumental Amphora Urn (Raw Chalk Matte, Dune Ochre Terracotta, Smoked Basalt Stone) with instant interactive status badges.
- Curated architectural trio product cards with limited-batch scarcity meters and social proof star ratings.

### 3. 🔥 "The 1926 Heritage Firing Kiln" Feature Card
- Bespoke gradient transitioning from luxurious deep forest green (`#122A1E`) to midnight charcoal (`#111315`).
- Artisanal lineage indicators highlighting 7-day slow air curing, double wood firing, and 1280°C vitrification.

### 4. 🛒 Full Client-Side E-Commerce Architecture
- **Interactive Slide-Out Atelier Bag:** Real-time quantity selectors, dynamic subtotal calculations, and interactive free crated delivery progress bar.
- **Multi-Currency Converter:** Instant live switching between USD (`$`), EUR (`€`), and GBP (`£`).
- **Promo Engine:** Redeemable promo codes (e.g., `ATELIER15` for 15% VIP collector savings).
- **Direct Order Processing & WhatsApp Concierge:** Frictionless checkout modal with direct WhatsApp structured invoice dispatch.

### 5. 📱 Mobile First Ergonomics
- Sticky mobile navigation pill with quick access to curation and cart count.
- Zero horizontal overflow, micro-animations, and thumb-friendly touch targets.

## 🛠️ Technology Stack

- **Markup & Layout:** Semantic HTML5, Tailwind CSS (modern typography & utility tokens)
- **Typography:** Playfair Display (High-End Serif) & Plus Jakarta Sans (Modern Clean Sans)
- **Icons:** Feather & Lucide Pro SVG icon system
- **State & Logic:** Native Vanilla JavaScript (Zero bloated frameworks, ultra-fast 60fps interaction)
- **Image Optimization:** Lossless/Perceptual WebP encoding embedded directly into HTML
